MODE: REVAMP an existing session.

The CURRENT DOC TO REVISE section below holds the session's existing doc. The
AUTHOR'S CHANGE BRIEF states what must change -- typically the outline and the
takeaways.

Rules for this mode, in priority order:

1. Apply the change brief. It is the requirement, not a suggestion.
2. Preserve everything the brief does not touch. Keep the existing Unit ID, unit
   number and position. Keep wording that already works -- a revamp is not a
   rewrite of prose that was fine.
3. Where the brief changes the outline, the hook and the Recap must still hold.
   If a changed outline breaks the hook, fix the hook and say so.
4. Reuse the existing doc's real outputs and traces. Do not discard a verified
   output and replace it with an unverified one.
5. At the end, under a `CHANGES MADE` heading, list every change as one line
   each: what changed, and which brief item it satisfies. A reviewer must be able
   to diff your output against the current doc using only that list.
